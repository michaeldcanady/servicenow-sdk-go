# Migration guide: v2 → v3 (Credentials rebuild)

This guide documents the breaking changes introduced by the credentials
rebuild (v3) and provides migration instructions.

## Summary of breaking changes

| Area | v2 (old) | v3 (new) |
| ---- | -------- | -------- |
| Provider construction | Functional options (`WithInstance`, `WithURL`, `WithHTTPClient`, etc.) | Per-flow option structs (`ClientCredentialsOptions`, `ROPCOptions`, etc.) embedding `CommonOptions` |
| Instance URL | Set on provider via `WithInstance`/`WithURL` | Set **once on the client** via `WithInstance`/`WithURL` |
| Credential types | Exported (`ClientCredentialsCredential`, `ROPCCredential`, etc.) | **Unexported** (implementation detail) |
| `Authority` type | Exported | **Unexported** |
| `GetAuthentication` adapter | Exported on `ROPCCredential` | **Removed** |
| Token store | `TokenStore` keyed by `clientID` string | `TokenStore` keyed by `TokenKey{Authority, ClientID}` |
| ROPC validation | Empty username/password accepted | Empty username/password rejected with shared sentinels |
| ROPC deprecation | Deprecated marker | **Removed** (discouraged in godoc, not deprecated) |

## Migration checklist

- [ ] Update all `New*Provider` calls to use per-flow option structs
- [ ] Move instance URL from provider options to client (`WithInstance`/`WithURL`)
- [ ] Replace exported credential type references with provider interfaces
- [ ] Update token store implementations to use `TokenKey{Authority, ClientID}`
- [ ] Update ROPC calls to validate empty username/password
- [ ] Remove `GetAuthentication` calls (use `AuthenticationProvider` interface)
- [ ] Update token store implementations for new `TokenKey` signature

## Code migration examples

### Client Credentials (v2 → v3)

```go
// v2
cred, err := credentials.NewClientCredentialsProvider(
    "client-id",
    "client-secret",
    credentials.WithInstance("myinstance.service-now.com"),
    credentials.WithHTTPClient(httpClient),
    credentials.WithTokenStore(store),
)

// v3
cred, err := credentials.NewClientCredentialsProvider(
    "client-id",
    "client-secret",
    credentials.ClientCredentialsOptions{
        CommonOptions: credentials.CommonOptions{
            AllowedHosts: []string{"myinstance.service-now.com"},
            HTTPClient:   httpClient,
            TokenStore:   store,
        },
    },
)

// Instance is now set on the client:
client, err := sdk.NewServiceNowServiceClient(
    sdk.WithAuthenticationProvider(cred),
    sdk.WithInstance("https://myinstance.service-now.com"),
)
```

### Authorization Code — Private (v2 → v3)

```go
// v2
cred, err := credentials.NewPrivateAuthorizationCodeProvider(
    "client-id",
    "client-secret",
    credentials.WithInstance("myinstance.service-now.com"),
    credentials.WithPort(5001),
    credentials.WithStateGenerator(customStateGen),
)

// v3
cred, err := credentials.NewPrivateAuthorizationCodeProvider(
    "client-id",
    "client-secret",
    credentials.AuthorizationCodeOptions{
        CommonOptions: credentials.CommonOptions{
            AllowedHosts: []string{"myinstance.service-now.com"},
        },
        Port: 5001,
    },
)
```

### Authorization Code — Public (v2 → v3)

```go
// v2
cred, err := credentials.NewPublicAuthorizationCodeProvider(
    "client-id",
    credentials.WithInstance("myinstance.service-now.com"),
    credentials.WithPort(8080),
)

// v3
cred, err := credentials.NewPublicAuthorizationCodeProvider(
    "client-id",
    credentials.AuthorizationCodeOptions{
        CommonOptions: credentials.CommonOptions{
            AllowedHosts: []string{"myinstance.service-now.com"},
        },
        Port: 8080,
    },
)
```

### ROPC (v2 → v3)

```go
// v2
cred, err := credentials.NewROPCProvider(
    "client-id",
    "client-secret",
    "username",
    "password",
    credentials.WithInstance("myinstance.service-now.com"),
)

// v3
cred, err := credentials.NewROPCProvider(
    "client-id",
    "client-secret",
    "username",
    "password",
    credentials.ROPCOptions{
        CommonOptions: credentials.CommonOptions{
            AllowedHosts: []string{"myinstance.service-now.com"},
        },
    },
)
// Note: Empty username or password now returns ErrEmptyUsername/ErrEmptyPassword
```

### JWT (v2 → v3)

```go
// v2
cred, err := credentials.NewJWTProvider(
    "client-id",
    "client-secret",
    tokenProvider,
    credentials.WithInstance("myinstance.service-now.com"),
    credentials.WithScopes([]string{"read"}),
)

// v3
cred, err := credentials.NewJWTProvider(
    "client-id",
    "client-secret",
    tokenProvider,
    credentials.JWTOptions{
        CommonOptions: credentials.CommonOptions{
            AllowedHosts: []string{"myinstance.service-now.com"},
            Scopes:       []string{"read"},
        },
    },
)
```

### External OIDC (new in v3)

```go
// v3 only
cred, err := credentials.NewExternalOIDCProvider(
    "client-id",
    credentials.ExternalOIDCOptions{
        CommonOptions: credentials.CommonOptions{
            AllowedHosts: []string{"myinstance.service-now.com"},
            Scopes:       []string{"openid", "profile", "email"},
        },
        Issuer:       "https://login.microsoftonline.com/{tenant}/v2.0",
        TokenSource:  credentials.ExternalOIDCTokenSourceIDToken, // default
    },
)
```

### Instance URL: Provider → Client

```go
// v2: Instance on provider
cred, err := credentials.NewClientCredentialsProvider(
    "id", "secret",
    credentials.WithInstance("https://myinstance.service-now.com"),
)

// v3: Instance on client (once)
cred, err := credentials.NewClientCredentialsProvider("id", "secret", opts)
client, err := sdk.NewServiceNowServiceClient(
    sdk.WithAuthenticationProvider(cred),
    sdk.WithInstance("https://myinstance.service-now.com"), // HERE
)
```

### Token Store: `clientID` → `TokenKey`

```go
// v2
type MyTokenStore struct{}

func (s *MyTokenStore) Save(ctx context.Context, clientID string, token *credentials.AccessToken) error { ... }
func (s *MyTokenStore) Load(ctx context.Context, clientID string) (*credentials.AccessToken, error) { ... }
func (s *MyTokenStore) Delete(ctx context.Context, clientID string) error { ... }

// v3
type MyTokenStore struct{}

func (s *MyTokenStore) Save(ctx context.Context, key credentials.TokenKey, token *credentials.AccessToken) error { ... }
func (s *MyTokenStore) Load(ctx context.Context, key credentials.TokenKey) (*credentials.AccessToken, error) { ... }
func (s *MyTokenStore) Delete(ctx context.Context, key credentials.TokenKey) error { ... }

// TokenKey structure:
type TokenKey struct {
    Authority string // instance URL or OIDC issuer
    ClientID  string // OAuth client ID
}
```

### ROPC: Empty username/password now errors

```go
// v2: accepted empty strings (runtime failure later)
cred, _ := credentials.NewROPCProvider("id", "secret", "", "pass", opts)

// v3: fails fast with shared sentinels
cred, err := credentials.NewROPCProvider("id", "secret", "", "pass", opts)
// err == credentials.ErrEmptyUsername
```

### Removed: `GetAuthentication` adapter

```go
// v2: ROPCCredential implemented core.Credential with GetAuthentication()
cred := &credentials.ROPCCredential{...}
header, err := cred.GetAuthentication() // returns "Bearer <token>"

// v3: Use the standard AuthenticationProvider interface
provider, err := credentials.NewROPCProvider(...)
client, err := sdk.NewServiceNowServiceClient(
    sdk.WithAuthenticationProvider(provider),
    sdk.WithInstance("https://instance.service-now.com"),
)
// The client handles authentication automatically
```

### Removed: `Authority` type and constructors

```go
// v2
authority := credentials.Authority("https://instance.service-now.com")
url := authority.TokenURL()

// v3: Authority is unexported. Use string URLs directly.
endpoints := oidc.Discover(ctx, "https://idp.example.com", httpClient)
// endpoints.TokenURL, endpoints.AuthURL, etc.
```

### Basic Authentication (unchanged, but now uses options)

```go
// v2
cred := credentials.NewBasicProvider("user", "pass")

// v3
cred := credentials.NewBasicProvider("user", "pass", credentials.BasicOptions{
    CommonOptions: credentials.CommonOptions{
        AllowedHosts: []string{"instance.service-now.com"},
    },
})
```

## Version compatibility

| Package | v2 | v3 |
| ------- | -- | -- |
| `github.com/michaeldcanady/servicenow-sdk-go/v3` | ✅ | ❌ |
| `github.com/michaeldcanady/servicenow-sdk-go/v3` | ❌ | ✅ |

The module path changes from `.../v2` to `.../v3`. Update your `go.mod`:

```go
module your/module

go 1.22

require github.com/michaeldcanady/servicenow-sdk-go/v3 v3.0.0
```

Run `go mod tidy` after updating.

## Verification

After migration, verify:

1. All provider construction calls compile
2. Instance URL is set exactly once on the client
3. Token store implementations use `TokenKey`
4. ROPC calls validate empty username/password
4. Integration tests pass against your ServiceNow instance
