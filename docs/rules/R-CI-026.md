# mise.toml is the source of tool versions, and CI pins must match it

<!-- Keywords MUST, MUST NOT, SHOULD, SHOULD NOT, MAY are interpreted per RFC 2119 / RFC 8174 (https://www.rfc-editor.org/rfc/rfc2119). -->
<!-- Replace Verify with the drift-check mise task once it exists. -->

MUST: Change a tool's version in `mise.toml` first.
MUST: Keep every CI version input for golangci-lint, Vale, zizmor, and Node equal to `mise.toml`, unless the action reads a version file that `mise` also reads.
SHOULD: Point an action at a shared version file, such as `go-version-file: go.mod`, when `mise` reads the same file.
MUST NOT: Pin the CI Go test matrix to a concrete version; it uses the `stable` and `oldstable` aliases.
MUST NOT: Replace native actions with `mise` task calls without a new ADR.

## Verify

```bash
# Fails when a CI pin for golangci-lint, Vale, or zizmor differs from mise.toml.
pin() { sed -nE "s/^\"?$1\"? = \"([^\"]+)\"/\1/p" mise.toml; }
g="$(pin golangci-lint)"; v="$(pin vale)"; z="$(pin zizmor)"
[ -n "$g" ] && [ -n "$v" ] && [ -n "$z" ] || exit 1
grep -qF "default: \"v$g\"" .github/workflows/reusable-lint-go.yaml || exit 1
grep -qF "default: \"$v\"" .github/workflows/reusable-vale-lint.yaml || exit 1
grep -qF "default: \"$v\"" .github/workflows/reusable-docs-gate.yaml || exit 1
grep -qF "default: \"$z\"" .github/workflows/reusable-zizmor.yaml || exit 1
```

## Rationale

Unchecked comments let local and CI tool versions drift, and native actions keep Dependabot updates and PR annotations. See [ADR 026](../../website/docs/contributing/adrs/026-tool-version-pins-and-drift-check.md).
